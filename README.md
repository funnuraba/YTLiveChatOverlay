# YouTube Live Overlay

YouTube Liveのライブチャットを、フルスクリーン動画の右側へ重ねて表示するMicrosoft Edge / Chromium系ブラウザ向け拡張機能です。外部APIやビルド処理は使用しません。

## インストール

1. Microsoft Edgeで `edge://extensions` を開きます。
2. 「開発者モード」をONにします。
3. 「展開して読み込み」を選び、このREADMEと `manifest.json` があるフォルダーを指定します。
4. YouTubeの既存タブがある場合は、一度だけそのタブを再読み込みします。

Chromeでは `chrome://extensions` から同じ手順で読み込めます。

既に読み込み済みの拡張機能を更新した場合は、拡張機能カードの「再読み込み」ボタンを押した後、YouTubeタブも再読み込みしてください。拡張機能のバージョンが `1.5.1` になっていることを確認できます。

## 使い方

1. ライブ配信中で、ライブチャットが表示されているYouTube視聴ページを開きます。
2. YouTubeプレイヤーのフルスクリーンボタンを押します。
3. 最新のチャットが動画の右側に表示されます。オーバーレイ上でマウスホイールを回すと、保持している直近100件まで遡れます。
4. フルスクリーンを終了するとオーバーレイは消えます。
5. 拡張機能アイコンのpopupからON/OFFを切り替えられます。設定はブラウザに保存されます。

### 表示位置と大きさ

フルスクリーン中にオーバーレイを直接ドラッグして調整します。popup操作や編集予約は不要です。

- `Ctrl + 左ドラッグ`: 移動
- `Ctrl + Shift + 左ドラッグ`: 幅・高さ変更
- オーバーレイ上でホイール: 過去コメントをスクロール
- 青い丸の下矢印ボタン: 最新コメントへ戻る

修飾キーを押してオーバーレイ内からドラッグを開始した場合と、履歴をスクロールする場合だけ操作を捕捉します。通常時は枠線、ボタン、ハンドルなどを一切表示せず、`pointer-events: none`を維持します。ドラッグ中だけ位置確認用の細い枠線が表示され、マウスを離すと消えて設定が保存されます。

最新位置を表示している間は、新しいコメントへ自動的に追従します。ホイールで過去へ遡ると、コメント欄の下部に青い丸と白い下矢印のボタンが現れます。このボタンを押すか一番下までスクロールすると、最新位置へ戻って自動追従が再開します。ページを開く前の全履歴は取得せず、YouTubeのチャットDOMに読み込まれている範囲から最大100件を保持します。

ドラッグ中の座標更新はブラウザーの描画タイミングへ同期し、位置は0.1%、幅は1px単位で滑らかに反映します。

## 構成と動作

- `src/content/live-chat.js`: `/live_chat` iframeと視聴ページ直下に存在するすべてのチャット一覧を監視します。単一の`MutationObserver`で要素追加、テキスト変更、ID変更を検出するため、YouTubeが更新先や既存rendererを切り替える場合も新しいコメントを抽出できます。
- `src/background.js`: チャットiframeからの通知を、同じYouTubeタブのトップフレームへ中継します。YouTube側のiframe配置には依存しません。
- `src/content/youtube.js`: トップフレームで通知、YouTubeのSPAイベント、`fullscreenchange`、保存設定を管理します。
- `src/content/overlay.js`: 表示DOMの生成、最大100件の管理、履歴スクロールと新着追従を担当します。
- `src/styles/overlay.css`: 操作を妨げない `pointer-events: none` のオーバーレイ表示です。
- `src/popup/*`: ON/OFFと診断状態を表示します。
- `src/shared/settings.js`: ドラッグで変更する位置・大きさの初期値、範囲、入力値の補正処理を管理します。

オーバーレイDOMは `document.fullscreenElement` の子として追加します。これにより、通常の `document.body` の子がフルスクリーンのトップレイヤー外になって見えなくなる問題を避けています。縦動画でYouTubeの操作UIが自動的に消える際にプレイヤーDOMが更新されても、全画面要素の直下を監視してオーバーレイを再配置し、表示用スタイルを維持します。

フルスクリーン中は、YouTube標準チャットを閉じたときにチャットDOMの更新が休止する問題を避けるため、同じ動画の`/live_chat`を不可視の補助iframeとして維持します。補助iframeはフルスクリーン終了、popupのOFF、SPAでの動画切り替え時に破棄されます。

通常コメントに加え、Super Chat、メンバーシップ、ステッカー用の種別とアイコンURLも抽出できる構造です。本文内のYouTube絵文字や配信者が設定したメンバースタンプは画像URLとテキストを分離して取得し、画像として表示します。

## 権限

- `storage`: ON/OFFとドラッグ調整した位置・大きさの保存に使用します。
- content scriptの対象は `https://www.youtube.com/*` のみに限定しています。

`tabs`、`webRequest`、`scripting`、`<all_urls>`、外部APIは使用しません。

## 手動テスト

1. 拡張機能を「展開して読み込み」で追加できることを確認します。
2. ライブ配信ページを開き、チャット欄に新規コメントが流れていることを確認します。
3. 通常表示中は動画上にオーバーレイがないことを確認します。
4. フルスクリーンに入り、右側に投稿者名と本文がリアルタイム表示されることを確認します。
   - YouTube標準のフルスクリーンチャット欄が表示された場合は閉じても構いません。
   - 縦動画Liveでは数秒待ち、YouTubeの操作UIが自動的に消えた後も表示が残ることを確認します。
5. オーバーレイ上でホイールを回し、過去コメントへスクロールできることを確認します。
6. 過去コメントへスクロールすると青い丸の下矢印ボタンが現れ、押すと最新位置へ戻ることを確認します。
7. 過去コメントを読んでいる間は新着受信で位置が飛ばず、一番下へ戻すと新着へ自動追従することを確認します。
8. 101件以上受信し、保持件数が最大100件に保たれることをpopupの診断欄で確認します。
9. フルスクリーンを終了し、表示が消えることを確認します。
10. popupでOFFにし、フルスクリーンでも表示されないことを確認します。
11. popupでONに戻し、表示が再開することを確認します。
12. `Ctrl + 左ドラッグ`で移動できることを確認します。
13. `Ctrl + Shift + 左ドラッグ`で幅・高さを変更できることを確認します。
14. メンバースタンプを含むコメントで、画像名ではなくスタンプ画像が表示されることを確認します。
15. ドラッグや履歴スクロールをしていない通常時に動画操作を妨げないことを確認します。
16. ページを再読み込みし、ON/OFFと位置・大きさが維持されることを確認します。
17. YouTube内で通常動画からLive、Liveから別のLiveへ移動し、再読み込みなしで対象が切り替わることを確認します。

## 既知の制限

- YouTubeの非公開DOMを参照するため、YouTube側の要素名変更時は `live-chat.js` と `youtube.js` 冒頭の `SELECTORS` を更新する必要があります。
- チャットを閉じている、チャットが無効、年齢・地域・ログイン制限などでiframeが読み込まれない場合はコメントを取得できません。
- YouTube標準プレイヤーのフルスクリーンを想定しています。ブラウザ独自の動画ポップアウトやPicture-in-Pictureは対象外です。
- Super Chatやメンバーシップの特殊カード表現は簡略化し、投稿者名と取得できた本文を通常コメントに近い形式で表示します。

## 表示されない場合

1. `edge://extensions` で本拡張機能のバージョンが `1.5.1` になっていることを確認します。
2. 拡張機能カードの「再読み込み」を押します。
3. 対象のYouTubeタブを再読み込みします。Manifestやcontent scriptを更新しただけでは、既に開いているタブへ新しいコードは反映されません。
4. popupがONで、配信ページのライブチャットに新規コメントが流れていることを確認してからフルスクリーンにします。
5. popup下部の診断欄で、チャット監視状態、受信件数、フルスクリーン判定、Live判定、オーバーレイ状態を確認できます。

### Enhancer for YouTube併用時

Enhancer for YouTube 3.0.19では、独自コントロールバー、テーマ、フルスクリーン時のレイアウト変更が本拡張機能の表示位置へ影響する可能性があります。本拡張機能1.5.1では、オーバーレイを`position: fixed`にし、表示に必要なCSSを高い優先度で指定して対策しています。

診断欄が「受信: 1件以上」「全画面: はい」「Live判定: はい」なのに「Overlay: 非表示」の場合は、本拡張機能側の表示制御の問題です。「Overlay: 表示中」なのに画面上で見えない場合は、他の拡張機能によるCSS・プレイヤーDOM変更との競合が疑われます。その場合だけEnhancer for YouTubeを一時的にOFFにして比較してください。
